Browser converts your HTML and CSS into pixels visible on the screen.

Tokenization

Browser breaks HTML and CSS into small meaningful pieces called tokens.

Parsing

Browser reads tokens and understands their structure.

DOM Tree

A tree-like representation of HTML elements.

CSSOM Tree

A tree-like representation of CSS rules and styles.

Render Tree

Combination of visible DOM elements and their final styles.
